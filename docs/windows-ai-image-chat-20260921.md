# Windows AI 问图交互及设置页修复

2026-09-21，本地版本仍为 4.1.8；此次没有打包或发布新版本。

## 交互

- 普通截图进入问图后关闭截图层；钉图保留，并可返回钉图。两处入口共用样式，位于图片右侧中间，屏幕边缘按可用区域限制位置。
- 问图对话使用普通窗口层级，激活时不切换为置顶窗口；切换其他软件、最小化及恢复由 Windows 正常管理。图片预览只归属于对话窗口，不独立置顶。
- 问图快捷键与设置入口使用 `WindowActivation.Show` 显式恢复并激活窗口。首次创建空白对话，再次调用唤起已有对话并保留图片、消息和草稿；关闭后清除引用，下次新建。保留界面子进程已有的前台授权传递，不使用临时或永久置顶来代替激活。
- 设置提供默认开启的问图开关、打开空白对话的按钮以及独立快捷键。关闭开关后不提供新截图／编辑入口和快捷键；缺少在线配置时提示先配置。
- 对话可拖入或选择最多五张图片，点击放大，删除后后续发送不再附加该图。已排队请求保留提交时的图片快照；关闭对话取消请求并释放图片、队列、预览和网络资源。
- 用户消息在右侧、回答在左侧。发送后立即显示消息并清空输入框，可继续输入和排队；快捷提示直接发送。支持停止、继续队列、移回输入框，以及取消当前请求并优先执行选中排队消息的“调整方向”。迟到回答不会覆盖停止状态。
- 配置、具体模型、刷新、强度和返回按钮处于同一行。可获取模型列表或手动填写具体模型；选择仅用于当前对话，不改写保存的配置模型。图片栏发送后自动收起，支持手动展开／收起，添加图片时展开。

## 模型测试

在线配置新增模型用途：自动、文字翻译、图片问答、图片生成／编辑。自动识别 `images-*`、`gpt-image-*`、`dall-e-*` 为图片接口；服务商使用聊天接口的同名模型可手动指定用途。保留用户填写的模型名称，不替换模型。

文字模型继续执行真实翻译和完整性检查；图片问答测试执行图片内容识别；生成模型调用图片接口并校验实际返回图片。图片专用配置不混入文字翻译路由，后台状态刷新不自动发起付费生成测试。临时模型／强度的请求结果不污染保存配置的可用状态。

问图对话可展示生成图片、放大、保存以及选择用于下次提问。多图编辑使用 multipart；返回 URL 下载不转发模型 API 密钥，并对响应体、文件及解码像素设定预算。未配置强度时不添加强度参数；非默认值是否支持由服务实际返回结果决定。

接口依据：[OpenAI 图片生成文档](https://developers.openai.com/api/docs/guides/image-generation)。第三方别名、模型能力和参数兼容性仍需要对应服务实测；本次未上传用户图片或消耗用户在线额度，网络测试使用模拟 HTTP 响应。

## 设置页回归原因与修复

`ArrangeTranslationPage` 原来按根面板的子控件序号提取内容。新增问图按钮、开关和说明后，序号偏移导致在线配置面板未重新挂回页面，问图控件被误放入离线引擎行。配置数据没有因此删除；只读核对源码 Release 的实际配置文件，两项在线配置和一项公共翻译配置仍存在。

修复改用具名控件与分组引用。问图开关和打开按钮同行，说明紧随其下；在线配置列表完整显示在下方，离线引擎行恢复其标签及选择器。新增离屏回归构建真实设置窗口，检查列表父子关系、文字及图片模型均显示、问图不混入离线区域、按钮动作和开关联动，以及配置字段保留。

## 验证

- Release 构建成功；相关回归 273 项：258 通过、15 项真实桌面集成测试按约定跳过、0 失败。覆盖问图会话、图片接口、后台图像处理、设置、配置持久化、模型目录、翻译提供方、快捷键及钉图相关逻辑。
- 设置页新增两项离屏回归通过：清透琉璃 1040 像素宽、青瓷月桂 520 像素宽；查看完整页面渲染确认列表、分组、字体与按钮。聊天窗口另检查三个主题和 440 像素窄窗口，一行选择器及图片折叠行为通过。
- 不使用真实桌面输入或全屏测试图案；没有实测第三方服务的图像能力和延迟，不对所有硬件作性能保证。
- 本地验证日志和临时渲染图在记录结果后清理。开发运行入口继续使用源码 Release 目录。
- 后续移除激活时置顶的事件处理后，Release 构建通过，现有问图会话与布局回归 17 项全部通过；未运行真实桌面窗口切换集成测试。
- 随后修复快捷键仅调用 `Show()`、未恢复和显式激活的问题：Release 构建通过；问图、功能进程与快捷键相关回归 63 项通过。单独开启桌面测试开关运行 2 项恢复／激活测试，验证首次显示、被其他普通窗口覆盖后唤起、最小化恢复、草稿保留、输入框焦点及非置顶状态，均通过。测试未向模型发送请求；未模拟所有第三方置顶窗口或跨权限桌面。

窗口激活遵循 [SetForegroundWindow](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setforegroundwindow) 和 [AllowSetForegroundWindow](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-allowsetforegroundwindow) 的前台权限规则，只在用户打开／唤起窗口时请求激活，不轮询抢夺焦点。
