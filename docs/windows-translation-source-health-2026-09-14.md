# 短标题离线翻译与在线状态同步

## 离线翻译

真实标题 `Archdruid's Lunarwing Form` 已通过 OCR。CLD3 将其判断为 `cy`，置信度约 0.994，同时返回不支持该语言的错误。原代码因此在调用离线模型之前退出；分段处理还会把这一带错误的检测结果重新设置为源语言。

现保留用户明确源语言；自动检测失败或不支持时让所选多语言模型判断并翻译，不擅自设成英文。分段仅接受无错误的可靠结果。Hy-MT2 使用其目标语言提示；TranslateGemma 在无法确定源语言时使用自动判断提示，明确要求保留名字、所有格等内容。结果继续通过完整性与语言校验，并补充拦截中文译文夹杂韩语的情况。

已实际执行标题图片 → PP-OCRv6 → TranslateGemma 4B / Hy-MT2 1.8B 两条本机路径，均能返回中文。术语人工审查仍有问题：例如小模型曾将 Archdruid 译为“大法师”，TranslateGemma 曾音译为“阿德鲁伊德”。这是模型术语准确性限制，并非已解决的问题；不会将结果描述为标准游戏译名。通路回归与术语质量判断分开记录。

## 在线模型状态

实际在线请求发布按配置隔离的状态：HTTP 429 余额不足、凭据拒绝、响应失败等会更新设置页及持久化记录；请求成功可恢复。取消不更改状态。配置或密钥变化、删除配置与迟到旧请求都不会污染当前状态。设置页原有测试同样纳入顺序检查；失败原因通过状态提示查看。

状态来自实际请求或测试，不声称实时知道远程账户余额，也不添加常驻轮询。不变更用户启用项、顺序、模型或凭据。验证使用模拟 HTTP 响应，未调用用户在线账户。
