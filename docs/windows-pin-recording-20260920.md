## 钉图编辑

- 单图和组合图使用共用底部调整行；标注按钮去掉小下拉，首次进入不选工具、不显示颜色／px，并关闭画布的自动创建标注，选择工具后启用。
- 形状、箭头、双向箭头、线条、马赛克、文字和序号继续复用原有操作处理。单独松开 Shift 循环子选项并同步主图标，保留组合键、绘制约束和文字输入；工具栏关闭后解除钉图窗口上的监听。
- 表情三行纵向滚动，px 在右侧；表情按需构造，选择后更新主图标。展开只按屏幕边界约束，不重新选择图片另一侧的位置。
- 颜色面板优先向下；翻译直接执行，右键选全局语言，不绑定 F4。切换翻译状态时保留原有提示，并附加当前目标语言和右键说明。
- 按钮改用截图／录屏已使用的合并绘制表面，保持原主题样式与右下翻译状态。仍是 WPF 轻量实现，没有改为纯 Win32 工具栏；未宣称解决另一台机器的冷启动延迟。

## 录屏启动错误

明确发现 `ReplaceRecorderAsync` 中两处连续赋值问题：局部保存目录和旧录制器引用分别赋值时同时被设为 `null`。更改编码格式、帧率、系统声音、麦克风或麦克风设备后触发重建，会在原生采集开始前失败。现正确保留保存目录及旧实例，替换完成后再后台释放旧实例。

原日志只订阅录制器最终 `Failed`，构造／重建异常不经过这一事件；自动回退成功时第一次失败也没有记录，后台写入没有等待结束，目录不可写被忽略。新增 Release 中默认有效的必要错误日志：

- 覆盖打开录屏、每次原生启动尝试、尝试释放失败、中途失败与界面失败结束，保留原始异常／堆栈、阶段、显示适配器身份、分辨率、编码格式、帧率、声音开关及实际采集 API。
- 按录制器会话和时间追加，串行后台写入；失败窗口结束前等待写完。自动回退成功也等待此前错误写完。没有屏幕／音频内容、输入追踪、逐帧日志、常驻写线程或轮询。
- 首选 `ScreenshotData/Diagnostics/recording-errors.log`，不能写入时回退 `%LOCALAPPDATA%/SnapCut/Diagnostics/recording-errors.log`。错误提示附实际路径；两处都失败时明确说明保存失败。主文件最大 512 KiB，保留一份 `.previous` 轮换备份。
- 保留原生首帧确认、一次兼容重试、用户编码／分辨率／帧率／声音设置及硬件失败记忆。取消不记为启动错误。

没有另一台电脑当时的提示及硬件信息，无法还原此前两次失败，也不能确认它们都由上述赋值问题造成。
