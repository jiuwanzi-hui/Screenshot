# Windows 首次框选显示与混合文字翻译回归（2026-09-16）

## 问题与修复

本次只改 Windows。保留现有 Mac 修改、长截图算法与用户配置，不发布或推送。

上一版常驻框选窗口在每次鼠标移动时，直接向窗口 DC 依次绘制原图、遮罩、选区和取色框；中间的无遮罩画面可能被显示，造成闪动。它还将悬停窗口当成已完成的选区挖掉遮罩，并用通用面板颜色画一像素边线。这与原有截图层的悬停遮罩及主题选区边框不一致。

新增会话内 `ResidentSelectionRenderer`：先在离屏 DIB 合成完整画面，窗口只复制最终帧；同一悬停窗口内移动只重画新旧取色框覆盖的区域，选区变化才加入对应区域。空闲悬停保留中性遮罩，拖选及确认后才恢复选区原始亮度，选区边框取自原有主题的 AccentStart，使用原生选区的三像素厚度，悬停边线按 DPI 缩放。屏幕边缘取色也保持中心采样像素正确。原图只读，不把遮罩、边线或取色框传入编辑器。取消、失败或交接完成时销毁渲染 DIB、DC、字体、画刷；不常驻缓存整屏。

翻译存在两个过宽的跳过条件：包含汉字而没有三词以上英文句子的行被当成中文；含缩写且其他词首字母大写的短行被当成不可翻译的标识符。现在短行中的普通英文词也进入翻译，仅保留实际标识符、缩写、路径及已知嵌入中文的产品名保护。不能仅凭大写推断品牌，例如 `CPU Usage`、`API Reference` 均发送翻译。混合短行原样返回也不能作为成功覆盖结果。本机模型对混合中文英文补充要求：翻译普通英文词及大写技术标签，保留已有中文和缩写；没有改变所选模型、精度或提供方顺序。

## 验证

- 离屏实际 GDI 像素检查：GlassInk／GlassMist／AuroraMist，100%／150%／200%；首次悬停遮罩、主题边框、拖选原图亮度、原始捕获像素不变、边缘取色中心、会话缓冲释放。32 次移动和选区状态变化均与全新完整渲染逐像素一致，旧取色框和边框没有残留。检查输出 PNG；没有将合成测试图案显示到桌面。
- 首轮完整 Windows 测试：1795 通过、98 跳过、1 条旧测试预期不适用。旧测试要求含 `Release` 的中文行完全不参与翻译，与本次混合文字要求冲突；改为验证纯中文跳过、`OCR Host 和 Core。` 进入请求。最终相关回归 138 通过、1 条需显式启用本机模型的测试跳过。编译通过；已有分析器警告保留。
- 使用用户提供截图中真实选区，OCR 输出 `OCR Host 和 Core。`。Hy-MT2 首次测试仍原样返回，加入混合文字要求后两轮通过：`OCR主机与核心。`／`OCR 主机与核心。`。TranslateGemma 两轮均返回 `OCR 主机 和 核心。`。同时检查段落失败索引、关键译词、译文覆盖层是否认为内容有变化。模型均使用本机 RTX 5070 Ti，没有访问付费翻译接口或更改用户配置。
- Hy-MT2：OCR 428 ms；首次翻译含模型启动 2448 ms，连续 29 ms。TranslateGemma：OCR 327 ms；首次 2439 ms，连续 81 ms。未把这些时间推广到 CPU 或其他机器。
- 最新原生框选探针：2560×1440 桌面、GlassInk、两颗逻辑核心和 `DOTNET_PROCESSOR_COUNT=2`；六轮首次绘制完成为 102.0／75.0／64.0／67.3／62.5／66.3 ms。三轮取消，三轮交给原有编辑器；功能进程均退出，快捷键恢复。结束稳定专用工作集 39.44 MiB，总工作集 150.93 MiB、专用提交 73.34 MiB。没有清空工作集或施加工作集上限。

首屏时间从调用截图入口计到首次 WM_PAINT 完成，包含抓屏和离屏合成，不含物理键盘和桌面合成器下一次显示延迟，也不是编辑器或 OCR 完成时间。离屏逐像素测试无法代替所有显示器、驱动和实际鼠标交互的验证。40 MiB 是本机稳定空闲的专用工作集观测，不是运行期间或所有机器的硬保证。

证据：`artifacts/resident-selection-rendering/` 中的 TRX、离屏 PNG、`native-runtime.txt` 和 `native-memory.csv`。早期失败记录保留，最终相关回归为 `final-targeted.trx`，两个真实模型分别为 `mixed-real-prompt.trx`、`mixed-real-gemma.trx`。

## 恢复居中主题启动提示

按用户随后反馈，取消常驻入口的 Windows 气泡通知，恢复原有 `StartupFeedbackWindow` 的主题样式、居中位置、淡入淡出和“已最小化启动”文字。通过现有功能进程显示；提示消失且没有其他活动后，该进程退出，常驻进程继续监听快捷键。不改用户主题或启动设置。

相关 22 项回归通过。实际窗口检查确认居中、不抢焦点、不在任务栏显示；保存真实提示视觉为 `themed-startup.png`。恢复主题提示后的六轮冷框选为 73.9／53.1／64.9／66.2／65.7／75.9 ms，提示进程与六轮功能进程均正常结束。最后稳定采样专用工作集约 40.08 MiB（此前几秒 40.57 → 40.08），总工作集 151.35 MiB、专用提交 72.85 MiB。此结果接近 40 MiB，但不能宣称严格低于 40 MiB；保留真实数据，不强制清空工作集。证据为 `themed-startup.txt`、`themed-native-runtime.txt`、`themed-native-memory.csv` 和 `themed-startup-regression.trx`。
