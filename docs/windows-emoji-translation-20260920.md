# Windows 表情列表与翻译入口调整

2026-09-20 根据最新反馈调整，仅改 Windows，版本号仍为 4.1.7。本记录取代同日早先的表情横向单行及翻译二次确认交互约定。

- 截图和录屏表情区恢复 WrapPanel 网格，固定显示三个完整行高，使用纵向滚动条；滚轮按整行滚动，禁用横向滚动，避免横向半个图标难以选取。
- px 保留在表情区域右侧，右下状态文字留出宽度；保留当前工具栏锚点和屏幕边界限制。表情仍按首次使用才创建，没有常驻预加载。
- 单击“译”直接使用当前全局目标语言执行原有 OCR／翻译流程。已有结果继续切换原文／译文，保留撤销、重做和失败重试。
- 右键整个“译”按钮，或聚焦后使用 Alt+下键选择目标语言。菜单按需创建，当前语言勾选；换语言只更新选择及失效旧译文，不额外调用模型。悬停提示包含目标语言及右键提示。
- 删除底部的语言确认行、“开始翻译”按钮和对应未使用的辅助样式，其他编辑窗口已有语言选择入口保留。

验证：40 项相关 Release 回归通过，覆盖三行高度、窄／宽布局、每个表情左右边缘、滚至最后一项、px 在右侧、工具栏锚点、语言选择不发请求及一次点击发起翻译、缓存切换与撤销重做、Shift 变体及隐藏工具栏准备。离屏图片检查完成，记录在 `artifacts/windows-emoji-translation-20260920`。未重新测量首次启动耗时，未在其他硬件或反馈视频的故障机器验证。

后续右键反馈：截图层的 PreviewMouseRightButtonDown 先于按钮语言菜单执行，会撤销标注或在松开时关闭截图。现让“译”按钮及其图标、Run 文本节点的右键事件继续交给 WPF 菜单，截图背景的撤销／退出保持原逻辑。移除语言菜单的 F4 绑定及悬停提示，不占用用户配置的功能键；保留右键与聚焦后的 Alt+下键。

补充验证：46 项相关 Release 回归通过。右键回归在隐藏 HWND 中走实际 WPF 预览鼠标路由，覆盖按钮、图标及 Run，随后补强并通过 3 项编辑状态用例，确认无标注时不登记退出、有标注时不撤销、背景右键仍撤销；菜单功能键回归覆盖 F1、F4、F12。未注入全局鼠标输入，其他机器的真实操作由临时便携包继续验证。
