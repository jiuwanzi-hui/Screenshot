# Windows 关闭窗口后的内存与资源释放

范围仅为 Windows。保留进入任务时已有的 Windows/macOS 修改；未修改 macOS、长截图采集与拼接算法、模型质量或用户设置。

## 当前结论

修复了实测发现的已关闭设置窗口被 UI Automation 引用保留，以及视频预览、导出取消和缓冲池释放的遗漏。**尚未达到所有操作结束后回到冷启动约 33 MiB 的目标，不能按目标已完成验收。**

## 本次修复

- 设置窗口隐藏且没有下载/子窗口等任务时，退役等待从 15 秒缩短为约 2 秒。下载仍可继续；关闭后不再接受迟到的设置保存回调。释放二维码和头像图像、拖动反馈。
- 堆分析发现 `ElementProxy → ListBoxItemAutomationPeer → TextBlock → MainWindow` 的 COM 强引用链；应用的 `MainWindow` 字段已置空仍不足以回收它。对已经真正关闭的窗口收集对应辅助功能提供者，离开关闭消息栈后在后台调用 `UiaDisconnectProvider`。不关闭整个进程的辅助功能、不触碰其他存活窗口，不为未创建辅助功能树的窗口主动建立整棵树。
- 视频预览会话支持异步释放：取消等待中及进行中的抽帧，再与抽帧串行清空 WinRT 媒体组合。原生资源释放在后台完成；关闭时立即解除预览图、时间轴图及播放器来源。
- 录屏后处理关闭时取消裁剪、GIF/WebP 导出与预览初始化；拒绝迟到的结果、进度和剪贴板操作。历史视频缩略图的超时直接取消原生操作，结束后释放预览会话。
- GIF/WebP 使用每个任务独立的 ImageSharp 分配器，任务内仍复用缓冲，完成/取消/失败后释放缓存；部分输出文件清理不影响原始视频。输出尺寸、帧率、编码质量保持原逻辑。
- 录屏原生释放完成、识别和翻译结果窗口关闭后，通知既有的合并回收机制。没有增加周期性 GC、工作集限制、清空工作集或自动重启。

微软要求在元素销毁后断开其 UIA 提供者，并明确禁止从同步 SendMessage 调用栈直接执行该操作，见 [UiaDisconnectProvider 文档](https://learn.microsoft.com/en-us/windows/win32/api/uiautomationcoreapi/nf-uiautomationcoreapi-uiadisconnectprovider)。这里的根引用结论来自本机转储，不是仅从框架问题报告推断。

## 设置窗口实测

Intel Core Ultra 7 270K Plus，24 核/24 线程，约 63.4 GiB 物理内存，RTX 5070 Ti。独立默认配置，真实 App 入口、托盘与悬浮按钮；设置窗口透明、不激活，正常创建/显示/关闭，不修改用户配置或剪贴板。每轮关闭后等待 45 秒；计数器约每 4 秒采样。MiB = 1,048,576 字节。

| 同进程阶段 | 专用工作集 | 总工作集 | 专用提交量 | 仍存活的已关闭设置窗口 |
| --- | ---: | ---: | ---: | ---: |
| 修改前启动稳定样本 | 约 31.5 MiB | 约 131.3 MiB | 约 62.4 MiB | 0 |
| 修改前三轮关闭后的末次样本 | 84.35 MiB | 236.76 MiB | 153.55 MiB | 1 |
| 修复后启动稳定样本 | 32.23 MiB | 131.66 MiB | 63.30 MiB | 0 |

修复后每轮的窗口弱引用均自然失效，没有测试专用强制 GC。上述修复后测量不包含取转储，诊断转储单独进行，其后的样本不拿来比较。两组初始化/后台活动存在差异，不据此宣称精确降幅比例。窗口已释放不代表运行库、渲染及分配器全部开销已卸载，剩余差异不能全部定性为泄漏，也不能未经进一步分配追踪就全部归为正常缓存。

## 验证

- 辅助功能专门回归通过：关闭旧窗口后旧列表项接口不可用，另一个窗口的接口仍可读取；未启用辅助功能的窗口不会因清理创建接口树。测试窗口透明且不激活，无屏幕图案、输入注入或抓屏。
- 原生视频样本在离屏生成；预览重复创建/释放、GIF/WebP 取消后重试、像素颜色、多帧输出、MP4 裁剪、原始视频字节不变、文件可删除均通过。
- 真实 OCR 工作进程及轻量翻译 CPU/GPU 生命周期共 7 项通过：连续复用、取消、恢复、空闲实际退出及重新加载。OCR 本轮首次约 336 ms、连续约 50 ms、重载约 330 ms，主测试进程没有加载 ONNX。这是本机样本，不是低配机器保证。
- 第一轮全量运行暴露了本轮尝试清空设置 DataContext 引发关闭事件重入的问题，已撤销该操作并增加关闭状态防护。该次运行中止不能计为全量通过。另有鼠标快捷键测试出现不稳定结果，最终完整复核中均通过。
- 最终完整 Windows 回归：**1759 通过、0 失败、97 跳过**，共 1856 项，约 3 分 19 秒。默认未运行需要真实桌面输入/抓屏或额外模型配置的测试；辅助功能及真实模型回归单独显式启用并验证，如上所述。
