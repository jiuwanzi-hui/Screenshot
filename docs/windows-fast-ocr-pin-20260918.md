# Windows：Small 快速识别、冷启动交接与 175% 钉图

2026-09-18；继续使用 4.1.7-localtest，只替换本地 Windows 包。没有修改 macOS、长截图算法、用户选择的翻译模型或线上发行状态。

## 实际修改

- 普通图片恢复 PP-OCRv6 Small；保留同样的原图像素、1600 上限、置信度阈值、字符位置和硬件线程预算。Small 在原尺寸识别后保留已有的小选区有限放大重试。
- 仅最大边不超过 800、最小边不超过 400，且首轮为空或疑似竖排少量文字时，才按需加载 Medium，在原像素上执行一次增强及已有竖排恢复。增强替换非空 Small 结果前，须保留原来所有字符的顺序并增加文字；普通整页不会初始化 Medium。
- 使用现有目录和共同的方向模型／字符表。Medium 用户补充 Small 的两个文件，共 31,163,977 字节（约 29.7 MiB）；完整六个文件共 171,006,870 字节（约 163.1 MiB），不是运行内存。可用的旧 Small 安装保留；取消之前删除 Small 的迁移。仅 Medium 已安装但缺少 Small 的用户得到一次补充提醒，首次安装不提示升级。
- 截图触发即启动隐藏功能进程，与原始桌面抓取并行；抓到原图且原生框选显示之前，禁止功能进程接管输入。取消、抓屏失败和启动超时会解除等待并清理未就绪进程。当前设置通过管道快照传递，工具栏不再等待设置文件写盘；框选期间的实际工具栏预备和稳定画面交接仍保留。
- 钉图尺寸在 175% 下可能因浮点转换和 HWND 向上取整多出一个物理像素。旧逻辑将这个像素当作放大空间，每次截图重新插值。本次把它作为边缘余量，按原始像素绘制。组合钉图也改用物理像素计算预览，避免把 DIP 数值当成输出像素数。

## 实测

机器：Core Ultra 7 270K Plus、64 GB RAM、RTX 5070 Ti 16 GB；OCR 仍使用 CPU，以下不是反馈者电脑的保证。

| 样本／操作 | 耗时 |
| --- | ---: |
| 用户 1658×1115 网页，上一版 Medium | 约 5.32 秒 |
| 同网页，本次 Small 首次（含工作进程） | 2.070 秒 |
| 同网页，连续 | 1.511 秒 |
| 600×100 普通小选区，连续 | 41 ms |
| 620×110 中英文，冷／连续／空闲后重载 | 395／42／398 ms |
| 主动 OCR 框选准备／准备后首图 | 286／148 ms |

网页 Small 返回 93 个区域，连续结果一致；不将它和 Medium 的分段差异当作字符准确率结论。Small 原始引擎在同网页的 2／4／6／8／12／16 线程连续耗时约 2.94／1.83／1.59／1.48／1.43／1.43 秒，12 之后没有明显收益，因此保留已按拓扑、内存与负载限制的线程预算，未盲目占满核心。

艺术字真实样本依旧得到“鼠虎猴”和“牛兔鶏”，六个字符的位置均映射回原图，原始截图逐像素不变。“鶏”仍是模型的异体字误识别，不能称为完全准确，也没有硬编码六个答案。普通页面即使存在尺寸正确但内容损坏的 Medium 文件也能成功，验证其不提前加载增强模型。

620×110 样本的工作进程总工作集约 167.0 MiB、峰值总工作集 167.3 MiB、专用提交 123.7 MiB；这不是整页峰值或专用工作集。空闲约 10 秒真实退出，取消后也退出，下一次可以重新启动。测试进程同时跑过原生初始化故障测试，已预先加载 ONNX，不能用该测试进程的模块列表声称常驻程序加载了 ONNX；最终正常启动另行核对。

## 回归范围与限制

- 钉图新增的 73×80、188×202、411×418 三种 175% 原生向上取整尺寸在修复前全部失败，修复后连续 10 次每个像素保持不变。也覆盖 100%／125%／150%／175%／200%、真实聊天图、导出缩放和组合钉图。
- 第一组 91 项通过，包括真实艺术字、小黄字、不同选区边距、深浅背景中英文字、空白、迁移、隐藏工具栏配置和输入交接屏障。第二组 35 项通过，2 项依赖真实桌面输入的测试按项目约定跳过；包括取消、坏模型恢复、实际进程退出与资源预算。
- 隐藏工具栏离屏准备约 73–80 ms，接入图片约 0.5–0.7 ms。这不等于用户松开鼠标到屏幕最终显示的完整耗时。没有在反馈者电脑实测最终鼠标响应、175% 桌面合成或工具栏显示延迟，需使用测试包确认。
- 保留错误诊断，普通发行构建未开启输入追踪或性能日志。打包及附件校验结果见 `releases/4.1.7-localtest-validation.md`。

证据：`artifacts/fast-ocr-pin-20260918` 中的 TRX、JSON、小体积日志。本轮临时分析程序、打包与解压副本的清理被自动审批以“blocked by policy”拒绝，未换方式重试；具体残留路径见交付验证记录。模型、源码和用户原图保留。
