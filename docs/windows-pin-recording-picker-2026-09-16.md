# Windows 钉图、录屏首次框选与取色 C 键（2026-09-16）

## 修改范围与原因

仅修改 Windows，不改变 macOS、长截图算法、用户配置、录屏编码格式或首帧确认规则。不打包、发布或推送。

原生常驻框选之前只覆盖普通截图；钉图和视频录制仍先等待功能进程冷启动、创建 WPF 选区。现在这两个键盘入口共用原生框选。已有鼠标延续手势、带预捕获图像的入口仍使用原有生命周期。钉图与录屏保持自由比例，普通截图保留用户比例设置。

钉图将框选前保存的原始像素及物理选区交给功能进程，直接裁剪成钉图；没有第二次抓屏或打开编辑选区。录屏只交接坐标，不发送整屏图像；录屏边框和工具栏呈现后，通过带序号的管道确认先隐藏原生框选，再允许开始录制。设备枚举放在框选交接之后，关闭期间迟到的枚举结果不再写回界面。取消或过期交接关闭已经创建的钉图／待录制工具栏并释放交互状态。

原生框选 HWND 没有文字输入功能，但默认关联输入法上下文，中文输入法可能先处理 C。现在创建 HWND 后立即解除该窗口的输入法上下文关联，同时处理 C、Esc 和排队的 VK_PROCESSKEY。没有禁用线程级输入法、修改全局输入语言或禁用截图文字标注。接口依据：[Microsoft ImmAssociateContextEx 文档](https://learn.microsoft.com/en-us/windows/win32/api/immdev/nf-immdev-immassociatecontextex)。

## 验证

- Release 编译通过。相关协议、原生绘制、输入和录屏状态回归 102 通过，其中包含取消交接后钉图／录屏窗口关闭及交互状态释放，见 `artifacts/resident-selection-rendering/pin-video-ime-final.trx`。额外像素、取色跟随、录屏编码器及交互状态回归 46 通过、1 条桌面集成测试默认跳过，见 `pin-video-broader.trx`。
- 输入测试创建隐藏 HWND，验证框选窗口没有 IME 上下文，另一个窗口的上下文和线程键盘布局在创建、C 复制／Esc 取消及销毁后保持不变。测试不注入全局输入。
- 独立探针使用自己目录中的设置，实测原始 2560×1440 桌面、GlassInk、两颗逻辑核心预算。钉图首次绘制 89.5／70.6 ms；录屏首次绘制 66.3／68.4 ms；取消轮 64.6／69.9 ms。释放选区后钉图交接 241.5／191.4 ms，录屏工具栏交接 369.9／218.9 ms。首次绘制从调用入口计到 WM_PAINT 完成，不包含键盘硬件和显示器下一次合成刷新。
- 两次钉图检查物理区域 `120,160,640,360` 和 100 个原始像素采样均一致，未重新打开 WPF 选区。两次真正启动录屏，以编码器首帧为准分别为 525.0／472.4 ms；保存 MP4 时长 1.27／1.25 秒，大小 414533／22162 字节。测试关闭历史窗口和所有本次功能窗口，功能进程均退出、快捷键恢复。录屏启动不宣称瞬间完成。
- 六轮结束后稳定空闲专用工作集约 39.25 MiB，总工作集约 152.32 MiB，专用提交约 71.78 MiB。没有清空工作集或设置硬上限。该观测不等于所有机器、运行期间都能保证 40 MiB 以下。完整记录为 `pin-video-runtime.txt`、`pin-video-memory.csv`。
- 真实 Ctrl+Alt+S → C 按键测试在 `zh-CN` 输入布局下完成，颜色 `#9E9FA1` 写入剪贴板，随后功能进程退出，探针线程原布局恢复，见 `chinese-ime-hotkey-runtime.txt`。中文布局本身不能证明中文候选模式；进一步用独立文本框确认候选组合状态的尝试因前台焦点条件不成立而中止，没有向失焦窗口发送 C。记录保留在 `chinese-ime-composition-runtime.txt` 与 `chinese-ime-composition-focus-runtime.txt`，不能把它们计为候选模式验证成功，也未覆盖全部第三方输入法。

探针和短视频仅在本地 `artifacts/windows-idle-host/` 内，不加入安装包或发行附件。

## 取色复制改用主题通知

随后按用户要求移除原生取色的 Windows 托盘气泡，改为复用居中的 `StartupFeedbackWindow`。剪贴板写入成功后隐藏取色窗口，仅发送颜色文本到已启动的功能进程；整屏 DIB、渲染缓冲与原生窗口随本次框选结束释放。主题提示约显示 1.3 秒并淡出，不抢焦点、不进入任务栏、不拦截点击；没有其他任务或窗口时，功能进程在提示关闭后约 2 秒退出。其他活动仍按其自身生命周期继续。

Windows Release 编译通过，相关 22 项回归通过。独立探针使用自己的设置，连续三次向取色 HWND 发送 C，校验剪贴板颜色、当前主题资源、工作区居中、自动关闭和功能进程实际退出；每次复制结束均检查原生 HWND 已销毁且整屏像素指针已归零，常驻进程没有创建主题提示窗口。三轮均显示“已复制 #181818”，从调用取色入口到功能进程退出分别为 4199／4155／4142 ms。提示渲染结果已人工检查。

两颗逻辑核心预算、2560×1440 桌面下，三轮结束后稳定专用工作集 34.07 MiB、总工作集 138.52 MiB、专用提交 64.44 MiB；没有清空工作集。这是本机测量，不是硬内存上限。本次结论整理后删除专用验证目录、临时探针扩展和重复程序副本。
