# Windows 工具栏轻量化与底部调整区（2026-09-20）

## 改动范围

仅 Windows，沿用 4.1.7。未修改 macOS、长截图采集/拼接算法，未打包、提交或发布。

- 截图与录屏的按钮装饰改为 `ToolbarButtonSurface`：在同一 Border 绘制反射与边缘，保留原 Button/RadioButton/ToggleButton 的输入、提示、无障碍和选中动画。装饰不再各占一个 Grid、Border 和 LiquidGlassLens。反射使用原 Border 的绘制结果，因此透明渐变边缘保持原样。
- 截图的自定义颜色编辑器在首次打开时创建；移除原本同时构造但已隐藏的旧颜色编辑器。截图翻译菜单延迟到使用时填充。隐藏表情图标不再在构造时栅格化，而在布局时获取同质量位图。
- 标注按钮去掉右侧下拉箭头。形状、箭头、双向箭头、线条、马赛克、文字背景、序号格式/起始值使用底部调整区。原菜单处理器、右键入口、快捷键和绘图逻辑继续复用。录屏表情以有高度上限的滚动区展示。
- 未选中标注功能时，颜色与大小调整隐藏。选择工具后恢复对应工具的颜色、线宽/字号/表情大小；切换不重置偏好。截图状态提示保留原文，置于右下。
- 截图比例在底部选择。后续按用户反馈，翻译按钮先展开目标语言和“开始翻译”，确认后才发起请求；已有结果时保留单击切换原文/译文，功能快捷键仍使用已选语言直接执行。更改目标语言沿用全局同步和旧译文失效逻辑，右键/F4/Alt+下仍可打开语言菜单。
- 保留原生高回报率选区输入和约 2 秒 WPF 工作进程空闲退出。没有常驻预热、软件渲染强制回退、工作集清空或生产代码强制 GC。

## 离屏对照

下列性能数据属于第一轮轻量化；下方“同行排布与预选语言”后续修正没有重复执行时延对照，不将原测量当成最新布局的重新实测。

本机 Intel Core Ultra 7 270K Plus / RTX 5070 Ti。两个隔离 Release 构建，其他 Windows 工作区改动一致；基线只将本轮工具栏文件恢复为任务前版本。每个构建、每种工具栏各启动 5 个独立进程，每进程创建/关闭 3 次。无窗口 Show、录制设备、屏幕抓取或全局输入注入。

计时从窗口构造开始，包含隐藏 HWND、布局和 RenderTargetBitmap 首帧；不包含完整应用启动，**不是鼠标松手到桌面上工具栏首帧的实测**。数字为独立进程首次处理的中位数：

| 指标 | 基线 | 修改后 |
| --- | ---: | ---: |
| 截图构造 + 离屏首帧 | 310.43 ms | 275.89 ms |
| 录屏构造 + 离屏首帧 | 204.42 ms | 186.08 ms |
| 截图 UI 线程首次托管分配 | 8.88 MiB | 6.89 MiB |
| 录屏 UI 线程首次托管分配 | 7.08 MiB | 3.57 MiB |
| 截图初始工具栏可视节点 | 204 | 114 |

初始节点减少包含“初始隐藏颜色栏”的产品变更，不能全部归因于装饰合并。连续创建时，截图构造约 64–74 ms、离屏呈现约 3.4 ms；录屏构造约 49 ms、呈现约 2 ms，与基线连续处理接近。没有把全部首次成本转移到模型或设备启动。

探针首次关闭窗口后、探针进程仍存活时的平均总工作集：截图 143.69 → 136.49 MiB，录屏 125.04 → 120.32 MiB；专用提交量：截图 129.31 → 124.69 MiB，录屏 96.77 → 91.57 MiB。它们不是应用空闲占用，也不是峰值或专用工作集。每轮关闭后 Application.Windows 都为 0；完整资源释放另由真实工作进程退出测试核对。

**限制：本次仍使用 WPF 控件和窗口。没有消除其运行时、D3D 设备与透明窗口冷启动成本；4800H 的松手到首帧表现仍需在目标机复核，不能宣称已经根治。** 原证据保留在 `windows-toolbar-systemtrace-20260919.md`、`windows-toolbar-render-ab-20260919.md`。

## 回归

- Release 相关测试 267 通过、9 桌面用例默认跳过；覆盖工具选择与选项实际效果、箭头命中区域、0.5/1/1.5 倍缩放、文字输入路由、右键/快捷键、序号、表情延迟加载、截图确认、比例、翻译、录屏收起布局以及取消准备。
- 原玻璃样式逐像素对照 6 个用例继续通过，未放宽像素断言。真实截图/录屏工具栏做了离屏预览；未为验证显示全屏测试图。
- 原本要求初始颜色栏可见、文字小箭头存在的测试按新需求更新，其他行为断言保留。
- 对 `FeatureToolbarPreparationTests` 单独开启桌面用例开关，仅运行无可见窗口、无设备启动、无输入注入的隐藏准备/取消验证：4/4 通过。截图 2/8 个逻辑处理器预算分别约 547.5/443.0 ms，录屏分别约 380.4/362.9 ms（含工作进程启动与隐藏工具栏准备，仍非桌面首帧时间）。四次均按命令编号完成取消和 idle/retire 握手，实际进程在超时内以 0 退出；没有残留 SnapCut 工作进程。逻辑处理器限制只用于本次验证，不能代表真实低端 CPU 或 4800H。

仅保留小体积指标、最终验证记录和预览；隔离基线源码、临时构建和重复依赖在交付前清理。

## 同行排布与预选语言（同日后续修正）

- 截图、录屏的颜色/px 与功能选项放进同一个自适应行。截图按主按钮行宽度约束，录屏按可用显示宽度约束；能同行时不拆开，放不下时换行，保留原有主题和右下状态文案。
- 修正“显示语言选择的同时已经发起翻译”的交互错误。选择目标语言本身不会调用 OCR/翻译，点“开始翻译”才执行；回归还验证已有结果的原文/译文切换、撤销重做和翻译快捷模式。
- 截图内嵌颜色面板、录屏独立颜色窗口都优先位于工具栏下方；下方空间不足时放到上方，并限制显示位置。截图同时更新原生遮罩的排除区域。录屏按目标显示器的工作区和 DPI 定位。
- Release 相关回归 78 通过、4 桌面用例按约定跳过；最后文案与预览调整后，18 项布局/语言/翻译相关检查再次通过。覆盖 950/330 DIP 同行与换行、实际隐藏 HWND 内颜色面板的上下位置、目标语言先选择后请求、原翻译覆盖逻辑与录屏布局。混合 DPI 的录屏颜色窗口没有进行真实桌面弹窗验证。
- 实际工具栏已离屏渲染检查，保留最新截图/录屏/语言选择预览；仍按原版本号从源码 Release 目录运行，不涉及发布。
