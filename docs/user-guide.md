# SnapCut 操作说明书

适用版本：SnapCut 4.5.6 · Windows 与 macOS。第一次使用可先跟着第一节截一张图，熟悉后可从目录跳到需要的操作。

## 一、第一次截图

1. 在 Windows 任务栏通知区域或 Mac 菜单栏打开 SnapCut，选择“截图”。也可以使用下表的快捷键。
2. 将鼠标移到目标窗口或控件上，观察候选框。需要自行划范围时，按住左键从一个角拖到对角。松手后拖边线或调整点微调。
3. 在工具栏选箭头、文字或高亮笔进行标注。完成时，在选区内的空白处双击左键，或按 Enter。要调圆角，先取消工具和标注选择，在选区内滚动鼠标滚轮，调好再双击。切回聊天框或文档，在 Windows 按 Ctrl+V，在 Mac 按 ⌘V。要另存文件可点保存。
4. 要截下拉菜单或悬停提示，先展开目标，再按截图快捷键。界面需要时间出现时可用延时截图；选错按 Esc 取消。

## 二、全局快捷键速查

下表列出新安装时的默认值。已有配置请以“设置 → 快捷键”为准。⌘ 是 Command，⌥ 是 Option，⌃ 是 Control，⇧ 是 Shift。“可设置”表示需要自行绑定。完成、撤销和重做仅在相应操作窗口生效。

| 操作 | Windows | macOS |
| --- | --- | --- |
| 区域截图 | Ctrl+Alt+S | ⌘⇧A |
| 完成框选 | Enter 或 Ctrl+C | Return 或 ⌘C |
| 取消框选 | Esc | Esc |
| 文字识别 | Ctrl+Alt+O | ⌘⇧O |
| 截图翻译 | 可设置 | ⌘⇧T |
| 输入框原位翻译 | Ctrl+Alt+Shift+T | ⌃⌥⇧T |
| 长截图 | 可设置 | ⌘⇧S |
| 区域录屏 | 可设置 | ⌘⇧R |
| 结束录制 | Alt+2 | ⌘⇧E |
| 截图钉图 | Ctrl+Alt+P | ⌘⇧P |
| 钉住剪贴板图片 | Ctrl+Alt+V | 可设置 |
| 打开设置 | Ctrl+Alt+, | ⌘⇧, |
| 撤销标注 | Ctrl+Z | ⌘Z |
| 重做标注 | Ctrl+Y 或 Ctrl+Shift+Z | ⌘⇧Z |

在设置里点要修改的快捷键，再实际按一次组合。当前屏幕全屏截图、预设区域、延时截图、划词翻译、Markdown 识别、AI 问图等可以按需绑定；穿透、实时翻译等以所在平台显示的项目为准。Windows 也支持鼠标侧键、修饰键和鼠标长按，长按时长可调。

## 三、取色、重复截图与长截图

重复截同一区域。临时复用上次范围可选“截图上次区域”，经常截固定范围可配置预设区域。使用“当前屏幕全屏截图”前把鼠标放在目标显示器上。

精确取色。Windows 框选时把指针对准目标像素，按 C 取色。取色提示中可用 Shift 切换颜色格式，方向键每次微移一个像素，长按加速。

网页长图和宽表格。框住实际能滚动的正文，点“长截图”。纵向模式在框内滚动；横向模式用触控板横向滚，Windows 也可用 Shift+滚轮。看预览确认新内容接上，再点对勾结束。遇到固定表头、工具条或侧栏时，尽量把它们留在选区外。

## 四、标注、橡皮擦与水印

框选后用形状圈出范围、箭头指向细节、序号标步骤。文字工具可输入说明，画笔和高亮笔用于手写及划重点。选中工具后查看它的样式栏，可调颜色、粗细、形状或字号。处理已有文件可从菜单进入“编辑图片”。

切换工具样式。Windows 工具提供多种子样式时，可轻按并松开 Shift 循环切换。在设置的工具栏与快捷键页可以调整工具的显示、顺序和局部快捷键。

框选去底色。选“橡皮擦 → 去除背景色”，拖框圈住目标再松手。让框的边缘接触想去掉的纯色或近似纯色背景；工具会清除从边缘连通的底色，保留文字和轮廓包住的内容。选错可撤销。透明结果建议保存为 PNG。

遮住账号等信息可用马赛克或隐私遮挡，导出前放大检查。要给截图署名，选水印工具，调整文字、图片及位置；常用水印在“设置 → 截图 → 水印”中配置。

## 五、钉图、拼图与收纳

钉住和编辑。截图后点钉图，或用“钉住剪贴板图片”直接钉住刚复制的图。右键可进入编辑，双击关闭。开启截图钉图的自动复制与历史后，新截图钉图会复制并记录；从剪贴板钉图沿用已有图片，不会再增加一条截图历史。

绘图中拖动整窗。未选择工具时拖空白处即可移动。在已选绘图工具时，Windows 用 Alt+左键拖动，Mac 用 Option+拖动。要改变可见范围，选裁剪工具再拖调整点。

组合与拆分。拖钉图靠近另一张的边缘，出现吸附预览后松手。图片也能部分重叠组合：拖到想要的位置，停约 0.3 秒，等预览出现再松开。从两图间的细接缝往外拖可以拆出其中一张，右键菜单也提供拆开组合。

启用“晾衣绳”后，按设置的呼出方式从屏幕顶边取用收纳内容，可调整停留时间、容量和自动挂入。Windows 的窗口穿透可设为按次切换或按住生效，按住模式在松开快捷键时恢复。

## 六、剪贴板与纯文本粘贴

启用剪贴板后，先点目标输入框，再用 Windows 的 Ctrl+Shift+V 或 Mac 的 ⌘⇧V 打开面板（默认快捷键）。按类型筛选或搜索关键词，单击一条记录即可粘贴到原输入框。要复制给别的软件，右键记录选“复制”。右键文字或链接可选“以纯文本粘贴”。图片可以钉到桌面，常用记录可以收藏、置顶或加标签。局域网同步需两端启用并配对，可选择同步类型。

Windows 面板按键。Ctrl+F 进入搜索，搜索框里 Enter 提交，↑／↓ 选择记录。列表里 Enter 粘贴，Ctrl+Enter 以纯文本粘贴；Ctrl+1 至 Ctrl+9 直接粘贴当前列表第 1 至第 9 条。Ctrl+空格 展开选中记录，Ctrl+E 编辑可编辑的文本，Delete 删除选中的列表记录。F1 查看按键提示，Esc 先关闭展开内容，再关闭面板。

## 七、录屏、音画对齐与导出

1. 从应用菜单选录屏，或在框选后点摄像机图标。确认范围、系统声音和麦克风选项后开始。录制中可暂停或继续；齿轮里的“输入显示”可切换鼠标、按键或两者的提示。
2. 结束录制，在编辑器预览下方点播放／暂停。拖进度条或点时间刻度跳到目标时刻。底部横向滚动条可以查看后面的缩略帧，声轨波形显示声音强弱。
3. 拖片段两端裁剪；拖片段中间移动整段。音画错位时，选声轨后左右拖，靠近画面轨起点或终点可以吸附。要让开头完全重合，点“对齐两轨起点”。右侧属性可精调起点、终点、静音和音量。
4. 试听后选导出格式。MP4 可选原始尺寸或输出高度上限；导出以保留的画面为准，仅保留与画面重叠的声音。动图可选 GIF、WebP；有声轨时可导出 M4A。导出另存，原录屏可从历史打开。

## 八、识别、翻译与 AI 问图

图片转文字用“文字识别”。需要标题、列表等结构用 Markdown 识别；表格可用表格识别／复制表格，数学表达式可用公式识别。结果请先核对，再复制到文档或电子表格。

文字在图片里，用“截图翻译”框选；文字能直接选中，用“文本翻译”；正在输入框写内容，可用“输入框原位翻译”。结果窗口可切换语言和服务。Windows 识别结果的原图可用 Ctrl+滚轮围绕指针缩放，放大后左键拖动平移，双击恢复适应窗口。

在“设置 → 翻译与 AI”选择服务。离线引擎先按提示准备语言包或模型，Windows 可按需下载或导入运行库。AI 问图需配置可用的模型服务，框选或导入图片后，再输入要问的问题。

## 九、设置、历史与故障排查

找设置。在设置搜索中输入“钉图”“水印”“快捷键”等词，点结果即可定位。铃铛查看公告，旁边的书本图标打开本说明书。Windows 设置导航可在同一分类内按住项目约半秒后拖动排序，也可用 Ctrl+Shift+↑／↓ 调整。

快捷键无反应。核对当前绑定与冲突提示，确认是否正在输入文字。工具栏快捷键须先进入相应的截图或编辑界面。Mac 首次使用请按功能提示核对屏幕录制、辅助功能等系统权限。

找回文件或迁移。已截图、已录制的内容分别到截图历史和录屏历史查找；复制过的文字、链接或图片到剪贴板历史查找。各自的保存目录或保留期限在设置中管理。换电脑前，可选择要备份的配置、历史和资源。

## 十、截图时的鼠标与键盘操作

**自动框选前**　把指针移到控件上，单击采用高亮范围。Tab 循环切换关闭检测、窗口检测、元素检测。元素框太小时，在 Windows 用 Alt、Mac 用 Option 扩大到父级，看到所需边界再单击。要画任意范围，直接按住左键拖动。

**框选时对齐或取色**　单独按下并松开 Ctrl（Mac 为 Control）切换截图辅助线。框选前可用方向键微调取色点，按 C 复制当前颜色。辅助线只用来对齐。

**框好后移动与裁边**　没有选画图工具时，拖动选区内部空白处移动范围，拖边或角上的调整点改变大小。用工具栏的比例选项可固定宽高比。

**滚轮在圆角与直角间调节**　普通截图框好并松开鼠标，把指针放在选区内部，避开工具栏，不按修饰键。未选绘图工具、标注或文字时，向上滚增大圆角，向下滚减小，减到零就回到直角。想设置具体半径，右键完成对勾，用圆角半径滑块。要保留透明四角可保存为 PNG。

**双击完成**　在已框好的普通截图内，左键双击空白处即可完成并复制。也可点对勾或按 Enter／Return。正在输入文字时，回车先换行；先点击文字框外结束输入，再双击空白处完成截图。

**标注时使用滚轮**　画笔、高亮笔等工具启用时，滚轮调整笔宽；选中可缩放的标注后，滚轮调整该对象的大小。要重新调截图圆角，先退出当前工具并取消对象选择。

**选择、修改和撤销**　双击已有文字可重新编辑；选中标注按 Delete 删除。Windows 普通截图画布右键优先撤销一步，无可撤销内容时会退出；在工具栏按钮上右键可打开该按钮的菜单。

**移动工具栏**　拖工具栏的空白处可挪开遮挡；在普通截图工具栏的空白处双击，可让工具栏回到选区边缘。双击工具栏和双击选区作用不同。

## 十一、工具栏按钮的右键菜单

把指针放在按钮图标上再点右键。Mac 触控板可用双指点按。菜单内容随窗口、工具和已配置的引擎变化。

**完成（✓）**　左键完成。右键可切换圆角截图、拖动半径滑块、开关完成后自动保存 PNG。展开“PNG 保存位置”可选默认目录或每次询问；选后者可记住并更改上次目录。

**保存**　左键选“保存到默认目录”或“另存为”。右键可选保存 PNG；画面含动画表情时，还能导出 GIF、暂停或恢复表情预览。

**文字识别（文）**　左键开始识别。右键选择 OCR 引擎，勾选同时识别表格、同时识别公式或小语种补充识别。需要相应模型时，到识别设置中准备模型。

**复制识别文字、表格识别**　右键复制识别文字可换 OCR 引擎。右键表格识别也能选引擎；Windows 还可开关“表格 AI 辅助”。启用并使用该功能时，会把原图与本地表格结果发给所选模型。

**Markdown 识别**　右键开关“允许 AI 增强”。识别后的结果窗口可主动执行增强，适合需要整理标题、段落或列表的文档。

**翻译（译）**　左键开始翻译。右键选择翻译服务和目标语言，选好后再执行翻译。

**去水印**　右键选择“AI 去水印”及已配置的图像模型。需要在线辅助时，先框住要处理的区域，再执行。

**绘图工具与颜色**　左键选工具后，在样式栏调线型、粗细、颜色、字号等。支持多个子样式的工具可轻按并松开 Shift 切换。Mac 上还可右键有子样式的工具选样式、右键序号选格式。Windows 调色板中，左键色槽取用颜色，右键用当前颜色覆盖色槽。

**更多与工具顺序**　常用按钮找不到时先打开“更多”。在“设置 → 工具栏”按住图标拖动排序，拖入或拖出“更多”区域；局部快捷键在截图或编辑窗口内使用。
