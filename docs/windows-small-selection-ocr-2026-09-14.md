# 小选区 OCR 漏检修复

用户样本：网页深色背景上的 `Archdruid's Lunarwing Form`。原实现对 265×63 的选区返回空结果，略缩小到 263×60 则能完整识别；直接原图和编辑画布导出的结果一致。故问题可在 PP-OCRv6 的小图检测路径独立复现，不是翻译提供方拒绝或仅仅不支持黄色文字。

共用高质量 OCR 服务保留原尺寸首轮识别；首轮没有文字区域且长边不超过 800、短边不超过 400 时，使用相同模型与置信度阈值进行一次 2 倍插值输入重试。最大输入为 1600×800，不对整页常规识别重复处理，不修改截图输出像素。结果区域、词框及字体大小换算回原图。临时图像随调用释放，取消仍会结束工作进程，空闲退出策略保留。

验证：Release 编译成功，28 项定向测试通过。包括真实样本四种边距与编辑导出、深浅背景彩色小字、中英混合、空白无误报、坐标映射、自动 OCR 选区更新与取消、跨进程像素传输、工作进程复用和空闲退出。测试夹具只保存 5.5 KB 的标题裁片。

本机该样本首次识别约 361 ms，连续识别约 32–39 ms（单次测量，非所有硬件时延保证）。本次验证的是翻译前置识别及原图位置，未使用用户账号请求在线翻译，也不意味着所有字体、分辨率和复杂背景都不会漏检。
