# Windows 自动长截图：代码编辑器步进与恢复交互（2026-09-20）

用户反馈：网页滚动正常，IDE 代码页面表现为逐帧跳动；失配后会反向回滚，点击未停止，实际向上时仍显示向下。本轮仅修改自动模式的匹配、恢复和控制反馈。手动拼接算法、预览放置及像素采集路径不变。

## 已确认的代码问题

1. 普通 `Click` 只在消费时才解释为暂停或继续。恢复过程中已经有点击排队时，旧代码可能先自动进入 `PausedDown`，再消费点击，于是原本的暂停意图变成重新启动。
2. 失配后的回滚最多执行八个完整滚轮刻度，没有和本段真实发出的输入关联；状态提示仍保留原采集方向。
3. 已有正文像素证据确认位移但超过预估上限时，精确匹配分支又落回近似搜索。编辑器按行累计滚轮的场景不应丢弃这一证据，再经历近似匹配、等待、重新取帧甚至回退。

## 修改

- 活动阶段的点击在输入钩子中标记为 `Pause`，迟到也不会触发继续。双击仍沿用已有返回流程。恢复、等待及重试阶段先检查控制请求，避免先改变状态或再次发轮；用户操作保持优先。
- 回退每轮最多 2～3 个刻度，同时按本段实际正反向滚轮累计量限制；保留两个刻度的在途呈现余量。同一旧位置不能反复补满回退额度。此约束是输入量上限，不把滚轮单位误称为固定像素距离。
- 反向校准期间显示实际校准方向；校准结束恢复原采集阶段文案。不调整预览窗口位置、大小、样式或显示状态。
- 像素匹配通过但位移超上限时，直接保留 `movement-cap-veto`，让现有控制器即时使用较宽的重叠范围验证同一帧；不降低正文一致性、方向与边界校验。
- 无法重连时显示正在核对／无法重连的明确反馈。最多记录八次本次会话的重连失败原因、尺寸与帧计数，随既有错误诊断在后台写入；不记录图片、代码正文或常驻输入轨迹。

## 验证边界

- 单张代码截图的普通回放和光标小块重绘回放原先即能通过，不能据此断言已复现用户 IDE 的全部实际呈现过程。
- 新增模拟编辑器累计滚轮后按行更新的服务级回放：120 单位后跳 84 行像素、40 单位后跳 196 行像素；两种设置均完整拼接，没有反向输入和恢复回合，输出与源区域逐像素一致。
- 用户截图用于本地可选回放，裁取左侧未被预览遮挡的 2000×1200 区域作为源像素，不改原附件，不随程序分发。环境变量 `SNAPCUT_CODE_SCROLL_SAMPLE` 指定附件。
- 恢复中排队普通点击与明确暂停动作均能停止后续滚轮，不被改判为继续；延迟暂停保持幂等。回退限额、方向提示与预览位置不变有独立回归。
- 原先可恢复的大位移／固定栏用例仍须通过，不能通过禁止全部恢复来掩盖交互错误。

这轮没有修改 IDE 自身的平滑滚动设置。浏览器和编辑器的滚轮呈现方式可能不同；用户实际 IDE、系统负载和滚动设置仍需使用新包复核，不承诺所有应用产生浏览器一样的动画。

## 19:29 反馈后的定位修正

上一轮未解决用户原场景。实际错误诊断 `scroll-20260920-192852-770.jsonl` 两次记录
`automatic-context-unverified`：选区 2219×732，已采集 4 帧，输出高度 802；约 9 秒和 18 秒时分别失配暂停。
这次失败发生在周边定位分支，根本没有进入上一轮优化的正文匹配分支。

自动模式在窗口较高时会扩展选区上下的取样范围，帮助小选区跨越空白。旧代码把该辅助范围的定位结果作为必需条件；IDE 选区外的独立面板或粘性标题变化可令辅助范围失配，即使选区正文仍有可靠重叠，也只能不断重连并最终暂停。上一轮代码图回放直接裁取正文，没有带上生产环境的 `ScrollCaptureContext`，因此未覆盖此路径。

本轮只为自动模式启用 `preferSelectedContent`：先使用选区内分布式、唯一的像素锚点确定位置，同时在这个实测位置更新正文和周边参考；正文不足以定位时，才沿用周边辅助匹配。未取得任何可靠像素证据时仍保留未确认状态，禁止猜测空白长度，失败帧也不替换最后一次可靠参考。额外的正文参考仅存活于本次采集，结束时释放。手动模式继续使用原有默认分支，预览与采集窗口位置不变。

新增回放确实覆盖了故障：选区外面板每帧变化、正文移动 28 像素时，旧代码的合成代码图和用户新附件代码区域均返回空位置，两个用例失败（`artifacts/scroll-context-before.log`）。修正后两者能连续定位；进一步覆盖 5 像素步进、空白与无证据帧拒绝、恢复后坐标连续性，以及整段自动向下采集、返回起点、向上扩展并逐像素检查最终结果。已有跨空白、固定栏与来回滚动回归也改为启用生产中实际使用的自动定位选项。

这是对实际日志所指分支的复现与修复，不把静态截图加模拟周边变化等同于现场录制的完整 IDE 帧序列。原 IDE 实际使用仍需复核。
