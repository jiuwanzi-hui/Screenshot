# Windows 后台识别、翻译与 AI 问图

版本：沿用本地 4.1.8，2026-09-21。此次为功能开发与 Release 验证，没有创建或上传新发行版。

后续问图交互、模型测试及设置页分组已更新，见 [AI 问图交互及设置页修复](windows-ai-image-chat-20260921.md)。下文记录初版实现；多图发送和普通截图关闭行为以新记录为准。

## 使用方式

- 截图和钉图编辑中的文字识别、翻译在后台执行，标注工具保持可用。
- 截图处理中点击工具栏的“后台处理”，截图层与原生边框、遮罩一起收起。通过任务栏返回当前截图，任务和标注继续保留。后台状态不会截走其他应用的 Ctrl+C／Esc，也不会由迟到的结果重新激活截图层。
- 如果等待期间继续修改标注或输入文字，识别、翻译结果先保留；再次点击“文／译”查看，不在回调中结束正在进行的文字输入。选区、图片或目标语言改变后，不应用旧任务结果。
- 截图框选完成、单张钉图及钉图编组编辑时，右侧提供“AI 问图”。窗口附加当前编辑结果，可输入要求、选择已有在线 AI 配置、多轮追问、停止请求或返回编辑。窗口及控件沿用主题；切到其他软件后不保持置顶。
- 缺少已启用且包含接口、模型与密钥的在线配置时，直接提示到“设置 → 翻译”配置。模型必须支持图片输入。公共翻译和离线模型不用于此入口。
- 打开对话框只附加图片，点击发送才调用选定接口。图片按原尺寸 PNG 传送，每轮上下文只带一份图片，包含此前对话。关闭窗口取消请求并释放图片、对话及 HTTP 资源；聊天的返回操作使用弱引用，不因独立聊天窗口保留已关闭的截图编辑器。

## 实现与验证范围

计算回调、PNG 编码和在线请求离开 WPF Dispatcher；画布快照及结果展示仍在 UI 线程。复用已有 OCR 工作进程、翻译资源调度和模型空闲释放机制，未调整模型质量、提供方顺序或长截图算法。每个问图窗口串行发送，响应大小上限 2 MiB，完整请求限时两分钟，可随时停止。

Release 编译成功。新增专项测试 19 项全部通过，覆盖：

- OCR／翻译回调运行线程、输入仍可用、切换选区后的取消和旧结果丢弃；
- 新标注保留、钉图重复点击不重复推理、完成后再次点击复用结果；
- 后台截图不截走复制与 Esc；
- 问图配置过滤、图片与多轮上下文请求、缺少密钥时不发送、鉴权／余额／限流状态同步、图片接口不兼容不污染文字翻译状态；
- 对话请求中仍可填写下一轮草稿，关闭后取消且不回写旧答案；
- 青瓷月桂、墨青豆沙、清透琉璃三个主题的离屏布局，包括窄窗口。使用完整应用控件资源，并查看渲染图确认文字、输入框和按钮。

相关回归最终执行 298 项：264 通过、33 跳过、1 项隔离桌面清理断言偶发失败。失败位于现有 `CaptureInputDesktopIsolationTests` 的 `CloseDesktop` 清理步骤；该类单独复验 4 项全部通过。33 项跳过包括需真实桌面输入的集成测试及已安装模型测试。此次修改的旧 OCR 测试已改为等待异步结果，并按项目约定归入桌面集成测试；其异步行为另有不显示窗口的专项测试覆盖。

没有向用户配置的在线服务上传实际图片；请求与错误使用模拟 HTTP 接口验证。实际服务的视觉能力、时延、配额与返回质量取决于所选模型，未做多硬件性能承诺。保留原有窗口、输入与 GPU 路径，此次不等于原生工具栏重构。

测试日志、TRX 和离屏渲染图在整理本记录后清理；源码 Release 程序及已有配置、模型继续保留。
