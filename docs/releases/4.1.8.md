# SnapCut 4.1.8

- 改善截图取色与框选的局部重绘、DPI 坐标处理，以及其他窗口争抢焦点时的输入接管，减少残影、边框缺失和截图就绪误判。
- 改善高回报率鼠标下单张及组合钉图的拖动响应，合并移动输入并按显示帧更新位置。
- 精简截图、录屏及钉图编辑工具栏的控件与展开流程，保留主题、悬停提示和操作手势。工具选项在底部展开，未选工具时不显示颜色与线宽；Shift 可切换子选项并同步图标。表情三行纵向滚动、线宽放右侧；翻译按钮直接执行，右键选择目标语言，不占用 F4。
- 优化 PP-OCR Small 的解码及多行识别调度，改善艺术字与局部裁剪漏检；新增可选 Qwen3-VL 4B 视觉识别，按需下载模型，不替换已有识别方式。
- 修复离线翻译的设备探测与加载问题，缓存硬件探测结果，按实际可用显存为轻量模型选择 GPU、混合或 CPU 路径。减少重复运行库准备，改善长正文调度，并在资源允许时重叠 OCR 与所选离线模型的加载。
- 修复译文被挤成小字、段落错误合并，以及技术文本中路径、数字和占位内容引起的漏译／误判；显示包含识别与排版的总耗时，保留具体失败原因及已完成段落。
- 修复调整录屏设置后重建录制器可能失败的问题，补齐启动、回退和运行错误的后台诊断，保留原始异常与实际日志路径。
- 修复宽选区长截图中预览遮挡区域出现黑条的问题。自动模式改善按行滚动匹配、周边面板变化引起的定位失败、暂停响应和回退方向提示，限制无效往返；手动拼接算法和预览位置保持不变。

说明：工具栏仍基于精简后的 WPF 实现，部分电脑空闲后的首次显示仍可能等待。OCR、翻译和视觉模型耗时取决于硬件与内容，不保证所有图片固定在 1 秒或 6 秒内完成；艺术字及不完整裁剪仍可能识别错误。自动长截图已通过代码图和周边变化回放验证，不同应用的实际滚动仍可能存在差异。

本次发布 Windows x64 安装版、便携 ZIP 和 7z。保留用户配置与已下载模型；默认包不包含模型权重、诊断脚本、源码或输入追踪。此次发布仅上传 GitHub。
