## 便携包与自动更新

7z 和 ZIP 解压得到相同的 12 个文件，完整保留 .NET、录屏和离线翻译推理依赖。7z 仅改变下载压缩格式，不改变程序运行方式；完整解压后运行 SnapCut.exe，Windows 10 等不支持解压 7z 的系统需使用解压软件。

4.0.2 起内置 7z 解压器，自动选择清单中的 portable7z，完成下载大小和 SHA-256 校验后在后台解压、覆盖、失败回滚及重启，无需用户安装解压软件。原 portable 字段继续提供 ZIP，供旧版更新器兼容。旧版首次升级仍需 GitHub ZIP；GitHub 不可访问时必须先手动下载一次 Gitee 包。升级到 4.0.2 后，后续版本可以直接通过 Gitee 7z 自动更新。安装版也继续通过 Gitee 安装包自动更新。

手动升级时先退出旧版，备份并保留 ScreenshotData 和 TranslationModels；将包完整解压到原程序目录，覆盖程序文件后重新启动。

## 后续打包

`installer/build-installer.ps1` 在保留 ZIP 的同时调用 `installer/build-portable-7z.ps1`，需要 7-Zip/NanaZip 命令行工具。脚本创建全新归档，运行完整性检查，并以严格小于 100,000,000 字节作为 7z 交付检查，避免压缩包增长后再次超过限制。
