# SnapCut 4.0.0

## 更新内容

- 重整设置页面与工具栏布局，统一图标、控件尺寸和菜单主题；增加自绘液态玻璃效果，改善小窗口适配和缩放时的响应。
- 调整录屏工具栏：准备录制时仅显示录制控制，录制中支持切换系统声音、麦克风；更新收起动画和悬浮控制按钮。
- 序号标注支持数字、字母和罗马数字，通过加减调整下一个序号，选择后立即生效；修复序号设置弹层松手即关闭的问题。
- 修复在线翻译配置编辑、重命名后接口地址和模型被重置的问题；改进真实翻译测试、分段完整性检查及失败原因提示，保留已成功翻译的段落。
- 保留 TranslateGemma 4B，新增可选的 Hy-MT2 1.8B 轻量离线模型；优化 CPU 推理线程、加载超时和闲置资源释放。模型需要在设置中单独下载。
- 改进多语言 OCR 的分栏处理，减少相邻新闻栏文字混合导致的翻译问题。
- 优化手动长截图的后台处理与预览刷新；修复上下反向滚动、漏帧后预览停止更新的问题，跟踪丢失时显示恢复提示。

## 下载与升级

- Windows 10 / 11 x64：安装版 `SnapCut-Setup-4.0.0-win-x64.exe`；便携版 `SnapCut-Portable-4.0.0-win-x64.zip`。
- 已包含 .NET 和录制所需运行组件，以及离线翻译运行程序；OCR、翻译模型按需下载。
- 升级前退出旧版。便携版请完整解压至可写目录，再运行 `SnapCut.exe`；保留原有 `ScreenshotData` 和 `TranslationModels` 可继续使用设置、历史与已下载模型，建议先备份。
- `SnapCut-Update.json`、`Screenshot-Update.json` 和 `SnapCut-Releases.json` 为更新元数据；`SHA256SUMS.txt` 提供附件校验值。
