# SnapCut 4.0.5

## 更新内容

- 修复截图使任务栏被其他窗口覆盖的问题；截取网页悬浮提示时先保存当前画面，再进入框选。
- 增加可选的框选后自动识别文字，普通截图和钉图可直接选择、复制文字；调整选区松手后合并识别，空白处保持拖动。
- 改善深色背景彩色小字、短标题和小选区的 OCR 漏检，减少普通文字被误判为微信小程序码。
- 钉图保留原始像素并按物理像素对齐；输出尺寸超过 100% 明确标为插值放大。
- 改善短标题及专有名称的离线翻译，源语言不确定时交由所选多语言模型处理；轻量模型按可用显存选择 GPU 或 CPU，并显示加载及回退状态。
- 在线模型实际请求失败和恢复后同步更新配置状态及原因；关闭新增翻译配置弹窗不再保存草稿。翻译配置和翻译优先顺序支持拖拽排序、落位动画及自动保存。
- 修复设置窗口缩放时内容拉伸、表单对齐问题，减少主题切换、保存设置和复制文本时的界面阻塞。
- 清透琉璃主题的界面文字统一使用黑色，修正透明区域自动改成白字的问题，保留玻璃材质和轻微文字边缘光影。
- OCR 改为按需独立进程，连续操作短暂复用，空闲约 10 秒后退出；优化后台资源释放和效率模式，前台操作恢复正常调度。
- 加固录屏首帧写入和编码兼容性；硬件编码失败时有限回退，记录实际失败条件以避免重复触发。
- 修复长截图中细字与动态图同时出现时，动态图边缘过密干扰位移判断的问题，保留对重复头像、不同正文和上下返回的校验。
- 修复 GitHub 不可达时的更新检测：Gitee 独立查询发行版及更新附件，支持安装版及 7z 便携版的下载校验、重试和覆盖恢复。

## 下载与升级

- Windows 10 / 11 x64：安装版 `SnapCut-Setup-4.0.5-win-x64.exe`；便携版 `SnapCut-Portable-4.0.5-win-x64.zip` 或 `.7z`。
- ZIP 与 7z 包含相同程序及完整依赖；Gitee 使用小于 100 MB 的 EXE 和 7z。已包含 .NET、录屏和离线翻译推理组件，模型按需下载。
- 4.0.5 支持 GitHub/Gitee 双源在线更新。较旧客户端如果无法检测 Gitee 发行附件，需要先手动升级一次，不能通过本次附件修复旧客户端自身的检测代码。
- 升级保留 `ScreenshotData` 和 `TranslationModels`；请勿删除已有设置、历史及模型目录。
- 自动更新附件：`SnapCut-Update.json`、`Screenshot-Update.json`、`SnapCut-Releases.json`；`SHA256SUMS.txt` 用于校验。

## 说明

离线模型对游戏、专业领域名称的译法仍可能与官方术语不同。运行占用和速度取决于模型、任务与硬件，本版不承诺所有机器空闲内存低于 20 MB。

本次仅提供 Windows 编译产物，不包含用户数据、密钥和调试追踪文件。后续源码、提交及标签仅保存在本地。平台自动生成的源码归档关联历史公开提交，不包含本版私有源码，请下载安装包或便携包。
