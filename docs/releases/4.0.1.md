# SnapCut 4.0.1

## 更新内容

- 重做“清透琉璃”主题：窗口透出底层真实内容，采用中性玻璃、柔和飘带和边缘反光；改善按钮、选中态、路径输入框和文字的可读性。
- 统一标题栏、应用弹窗、托盘菜单及截图工具栏的玻璃样式；导航、页签和工具按钮增加选中底框滑动过渡，长提示支持换行。
- 修复从其他主题切换到玻璃主题后，需要再次截图才能刷新背景的问题。
- 修复后台截图及右键菜单打开时的快捷键触发问题，改善菜单画面缓存和输入焦点交接；按住快捷键不会反复启动截图。
- 修复截图初始化时只有遮罩、无法框选，以及松开 Alt 后放大镜不再跟随的问题；优化尺寸提示与工具栏的避让。
- 优化钉图：默认直接显示图片，保留细边线与阴影；整图可拖动，进入编辑后锁定位置，常用识别、翻译、裁剪等操作集中在编辑工具栏。
- 改善 OCR 结果窗口的文字对比度，去掉多余内框；扩展常见隐私信息识别，减少打码波及相邻文字的问题。
- 改善长截图跨空白区域和上下往返时的衔接、边框显示及滚动闪烁问题；优化历史窗口从任务栏切回前台的表现。

## 下载与升级

- 支持 Windows 10 / 11 x64。
- 安装版：`SnapCut-Setup-4.0.1-win-x64.exe`。
- 便携版：`SnapCut-Portable-4.0.1-win-x64.zip`，完整解压后运行 `SnapCut.exe`。
- 已包含 .NET、录屏依赖和离线翻译推理组件；OCR 与翻译模型按需下载。
- 升级前退出旧版，备份并保留原有 `ScreenshotData`、`TranslationModels`，以继续使用设置、历史和已下载模型。
- `SnapCut-Update.json`、`Screenshot-Update.json`、`SnapCut-Releases.json` 为自动更新元数据，`SHA256SUMS.txt` 为附件校验文件。
