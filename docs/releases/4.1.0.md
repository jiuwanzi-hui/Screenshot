# SnapCut 4.1.0

- 新增普通截图水印：支持自定义文字、截图时间、城市／地区、经纬度和手填地点，最多导入三张图片并选择一张作为水印图案。
- 水印图案、文字、时间和地点可在预览中分别拖动、缩放与摆放；手填地点实时更新，设置样式跟随当前主题。
- 普通截图工具栏新增水印按钮，支持一键添加、取消及截图自动添加；移动或调整选区时暂时隐藏水印，调整完成后重新显示。
- 优化后台待机内存和资源回收，设置、截图、长图编辑、识别、翻译、钉图及录屏结束后及时释放对应资源。
- 加快普通截图、钉图和录屏框选的启动响应，修复首次截图遮罩、边框显示异常及取色移动闪烁。
- 修复中文输入法下按 C 无法复制颜色的问题；取色复制和最小化启动恢复居中的主题通知。
- 改进中英文混合内容、短标题和专业词语的翻译判断，修复包含外语的选区被误判为无需翻译的问题。
- 改进钉图原始像素保留、编辑交接、主题切换及窗口关闭后的资源释放。
- 更新交流群二维码，并改进在线二维码刷新，避免继续显示旧图片。
