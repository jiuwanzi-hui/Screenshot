# SnapCut 4.0.2

## 更新内容

- 加固休眠恢复和长时间闲置后的截图启动：修正屏幕像素透明度处理，确认冻结画面与输入就绪后显示遮罩；异常时有限回退并及时提示，避免重复采集叠加负载。
- 改善录屏启动兼容性：等待采集与编码器确认后显示正在录制，启动失败可尝试一次兼容采集与软件编码；保留所选格式、分辨率、帧率及声音配置，移除因黑色画面自动结束录制的误判。
- 优化 OCR 与离线翻译的硬件适配、首次加载、批量处理和任务结束后的资源释放；本地内存或显存不足时显示原因和处理指引。
- 改善多语言互译、同语言段落跳过、段落完整性检查与失败补译，保留已完成译文；新增百度、有道官方公共翻译接口配置，使用用户自己的应用 ID 与密钥。
- 翻译按钮增加目标语言下拉菜单，与设置和其他翻译入口同步；菜单、选中态和滚动条跟随主题，移入菜单边缘不再自动滚动。
- 新增紧凑的双线双向箭头标注，箭头仅保留外侧半边，支持实心与空心样式；同步普通截图、钉图、长截图结果编辑和录屏工具栏。
- 调整前六个主题配色，保持三浅色、三深色，雾紫主题采用柔和哑光效果；统一各主题的导航、页签和工具按钮切换动画。
- 修复设置窗口最大化遮挡任务栏及内容过度拉伸的问题；截图、钉图与录屏框选边框统一跟随主题。
- 改善钉图滚轮缩放流畅性，修复缩小时边缘出现白色尖角或条带；普通钉图和编组支持双击关闭，编辑状态保留原有双击操作。
- 长截图结果编辑工具栏增加识别文字、复制文字、表格识别和翻译入口；改善慢速机器上的采集响应及预览恢复，保留已拼接结果。
- 修复二维码识别圆点单击未复制的问题，避免选区拖动拦截识别结果点击。

## 下载与升级

- 支持 Windows 10 / 11 x64。
- 安装版：`SnapCut-Setup-4.0.2-win-x64.exe`。
- 便携版：`SnapCut-Portable-4.0.2-win-x64.zip`，完整解压后运行 `SnapCut.exe`。
- Gitee 便携版：`SnapCut-Portable-4.0.2-win-x64.7z`，小于 100 MB，与 ZIP 包含相同程序和完整依赖；系统不支持时使用 7-Zip/NanaZip 解压。4.0.2 起内置解压器可通过 Gitee 7z 自动更新；旧版首次升级需 GitHub ZIP 或手动下载一次 Gitee 包。
- 已包含 .NET、录屏依赖和离线翻译推理组件；OCR 与翻译模型按需下载。
- 升级前退出旧版，备份并保留原有 `ScreenshotData`、`TranslationModels`，以继续使用设置、历史和已下载模型。
- `SnapCut-Update.json`、`Screenshot-Update.json`、`SnapCut-Releases.json` 为自动更新元数据；`SHA256SUMS.txt` 为附件校验文件。
- 公共翻译服务的可用额度与限额以各平台账户为准；实际识别和翻译耗时取决于硬件、模型、文本及网络。
