# SnapCut 4.1.2

- 新增实时区域翻译：快捷键直接框选，持续识别并翻译区域中的外语，支持术语设置、增量更新和译文复用。
- 改进动态网页、文档和游戏画面的译文显示，优化原文覆盖、背景取色和段落排版，精简状态提示；远程查看时保留选区边框与译文。
- 完善中文、英文、法文、俄文、西班牙文和阿拉伯文界面切换，同步设置、工具栏提示、菜单和应用弹窗。
- 增强复杂表格识别，改善合并单元格、缺少两侧边线、三线表的结构与文字识别，并补识别遗漏的单元格内容。
- 工具栏快捷键支持 Ctrl、Alt、Shift 与数字组合，同步截图、钉图编辑和录屏标注。
- 普通截图工具栏新增比例选择，选中后立即调整选区，自动记住并同步设置页及工具栏布局预览。
- 文本标注新增有背景／无背景选项，背景随文字自动调整大小，选择持久化并同步普通截图、钉图、长图编辑和录屏标注。
- 修复工具栏下拉箭头点击不灵敏、文本背景不显示的问题；提前准备工具栏，将自动识别移至首帧显示之后，改善框选完成后的响应。
- 修复首次截图尺寸提示位置异常与松手闪屏，优化屏幕像素传递、窗口交接和任务结束后的资源释放。
- 托盘单击进入截图、双击打开设置；修复实时翻译选区坐标及关闭后的资源回收，并保留采集期间已打开的设置页面。
