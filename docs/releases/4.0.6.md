# SnapCut 4.0.6

## 更新内容

- 恢复清透琉璃原有文字配色：透明区域、标题、导航和识别正文使用浅色字，按钮与输入框保留适合其底板的深色字，修复黑色桌面背景下黑字难以辨认的问题。
- 优化主题切换：批量提交完整色板，合并设置窗口的重复刷新与保存，减少切换瞬间的界面卡顿；保留玻璃材质、选中动画和设置持久化。
- 保留 4.0.5 的截图、OCR、翻译、录屏和双源自动更新修复。

## 下载与升级

- Windows 10 / 11 x64：安装版 `SnapCut-Setup-4.0.6-win-x64.exe`；便携版 `SnapCut-Portable-4.0.6-win-x64.zip` 或 `.7z`。
- ZIP 和 7z 包含相同程序及完整依赖。Gitee 使用严格小于 100 MB 的 EXE 和 7z，GitHub 同时提供 ZIP。
- 支持 GitHub / Gitee 双源在线更新，升级保留 `ScreenshotData` 和 `TranslationModels`。旧客户端若缺少 Gitee 发行附件检测或 7z 支持，可能需要先手动升级一次。
- `SnapCut-Update.json`、`Screenshot-Update.json`、`SnapCut-Releases.json` 为更新所需附件，`SHA256SUMS.txt` 用于校验。

本次仅分发 Windows 编译产物。源码和本地提交不推送远程；平台自动生成的源码归档关联历史公开提交，不包含本版私有源码。
