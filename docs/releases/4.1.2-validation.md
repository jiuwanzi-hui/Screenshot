# Windows 4.1.2 发布验证

验证日期：2026-09-17。

## 构建与回归

- Windows Release 全量回归共 2080 项：首次 1958 通过、120 按桌面／外部依赖开关跳过、2 失败。两个失败都是旧测试通过反射调用新增可选参数的方法，未传参数；修正测试并等待延后的真实译文显示后，两项单独复测全部通过。产品逻辑未为测试更改。
- 打包前显式启用 `SNAPCUT_VERIFY_GITEE_UPDATE=1`，49 项更新回归全部通过，用时 1 分 47 秒。实际屏蔽 GitHub，从当前已发布的 Gitee 版本下载 EXE 和 7z，校验并在隔离目录应用便携更新，确认用户配置保留；不是对尚未发布的 Gitee 4.1.2 的线上验证。
- 修复 Windows PowerShell 5.1 对无 BOM 中文 JSON 的默认编码，以及 `ConvertFrom-Json` 多条历史记录被额外包成嵌套数组的问题。校验脚本明确读取 UTF-8，并直接接收解码数组；回归使用无 BOM 多语言正文与多条历史记录。
- 修复后的打包更新回归为 48 通过、1 项显式联网用例默认跳过、0 失败。联网用例已经在前一步实际执行通过。
- 本次只收录 Windows 代码、Windows 测试、版本、清单和发布文档。已有 Mac、共享 Core、AGENTS.md 和 README 中的 Mac 变更保留在工作区，不纳入本地发布提交。

## 分发兼容

- 4.1.2 保留完整 ZIP 和 7z，二者由同一个打包脚本从相同发布目录生成。
- 现有 Windows 更新器能解压完整 ZIP／7z；清单有 `portable7z` 时优先选择 7z，没有 ZIP 分片下载与合并能力。不能只上传分片就宣称旧客户端可自动更新。
- 本地源码提交和标签不推送。GitHub 发行目标使用已经公开的 main 提交 `f6394c1f78b7a4dd5a9a26feca6c2895ba738b95`，不引用本地私有提交。
- 面向用户的说明使用 `4.1.2.md`，只包含更新内容；本验证文档不上传为发行附件。
