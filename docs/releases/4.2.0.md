# SnapCut 4.2.0

- 新增 AI 问图：截图、钉图编辑及设置均可进入，支持独立快捷键、最多五张图片、图片预览与删除，以及总结、提取文字、翻译等快捷提问。
- 问图支持选择在线配置、具体模型与强度，流式显示回答及服务实际提供的思路内容；可继续输入、排队发送、停止和调整方向。支持兼容服务的图片生成／编辑，按模型用途执行配置测试。
- OCR 和翻译在后台处理，期间可继续标注或切换其他软件；改善问图窗口的主题、图片栏收起、快捷键唤起和普通窗口层级。
- 新增百度大模型文本翻译，与百度通用翻译分开配置；在线模型请求失败与恢复同步显示实际状态。
- 改善 PP-OCRv6 的竖排与描边艺术字识别，修正裁切方向、识别输入填充和字符框映射；优化像素预处理与 CPU 调度，减少已识别竖列的重复处理。
- “取”直接识别、复制文字并关闭截图；截图完成提示在屏幕中央显示约 0.8 秒，支持远程画面查看。进入 AI 问图仍执行截图完成流程，但不显示成功提示。
- 修复设置页面在线 AI 配置区域的布局与显示问题，保留已有配置、用户数据及下载模型。

## 下载与升级

- 支持 Windows 10 / 11 x64，提供安装 EXE、便携 ZIP 和 7z。
- 便携版完整解压后运行 `SnapCut.exe`；升级前退出旧版，备份并保留 `ScreenshotData` 和 `TranslationModels`。
- 包含必需运行组件，OCR／翻译模型按需下载；不包含用户数据、密钥、模型权重、源码或诊断脚本。
- AI 问图需要配置支持相应用途的在线模型；图片在发送时提交给所选服务。思路显示取决于接口实际返回内容。
- 艺术字准确率及 OCR／翻译耗时受图片、硬件和模型影响，复杂海报仍可能识别错误或耗时较长，不保证所有图片在 1 秒内完成。

从 4.0.0 起仅分发二进制，后续源码不再公开。平台自动生成的源码归档不包含本次版本源码，请下载安装包或便携包。
