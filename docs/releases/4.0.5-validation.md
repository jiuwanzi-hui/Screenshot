# Windows 4.0.5 验证记录

本次只提交 Windows 程序、测试、发布脚本和相应文档；已有 macOS 与独立 SnapCut.Core 改动保留在工作区，不纳入此提交。源码和本地版本标签不推送远程。

## 发布回归中发现并修复的问题

- 完整回归最初有 9 项长截图断言失败，定向运行通过。保存实际输入后确认：GDI 字体抗锯齿状态不同使细字边缘密度不同，密集动态图因此压过分散的文字证据。匹配改为合格纹理图块的空间权重，保留唯一位移、分布和正文一致性检查；固定的合成聊天样本覆盖上下运动、返回、静止动画和逐像素完整性。未修改 macOS/Core 中的另一套实现。
- 真实 OCR 回归时发现取色采样与界面查询 Bitmap.Width/Height 竞争。CapturedImage 在构造时记录固定像素尺寸，放大镜不再在界面线程查询正在采样的 GDI 位图；新增锁定位图的并发回归。
- 修正一项快捷键单元测试受用户真实键盘状态干扰的问题，使用现有键盘状态和按键释放替代接口，保留断言与产品逻辑。
- 自动返回恢复测试原先按收到 9 帧就结束，却断言已前进超过 200 像素；自适应采样不保证固定帧间位移。结束条件增加实际滚动距离要求，保留输出距离、恢复发生、不中途暂停和逐像素完整性断言。
- 清透琉璃文字统一为黑色，删除透明区域切回白字的行为；覆盖导航、标题、正文、输入、选中态、菜单和识别结果，不改变其他主题或截图标注颜色。
