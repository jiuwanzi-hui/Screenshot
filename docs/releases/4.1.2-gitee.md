## ZIP 分片与已有 7z 用户

以前从 7z 解压使用，不会把应用绑定为 7z 格式。现有更新器支持完整 ZIP 和 7z，清单存在 `portable7z` 时优先选择 7z。

当前 Windows 更新器没有分片列表、逐片下载校验和合并逻辑，所以仅上传 ZIP 分片不能让现有客户端自动更新。若以后统一为 ZIP 分片，需要先让用户升级到支持分片的过渡版本，同时保留旧客户端可下载的完整包。4.1.2 继续提供完整 ZIP 和 7z，由一个打包脚本自动生成。
