# SnapCut 4.1.7

- 改用短时原生剪贴板写入，减少与语音转录等软件复制文字时的冲突，完善占用重试和资源释放。
- PP-OCRv6 普通识别使用 Small 快速路径，艺术字、彩色文字和竖排漏检按需使用 Medium 增强；改善小选区及边缘文字处理，保留原始截图像素。已有模型继续保留，缺失组件可在“内容识别”设置中补齐。
- 根据硬件能力分配 OCR 与离线翻译线程和并行资源，改善首次加载、连续识别和大段翻译的调度；修复包含英文路径的正文被误认为目标语言而跳过翻译的问题。
- 改善设置打开时的输入响应、截图与录屏工具栏交接，以及空闲后取色窗口的显示一致性；保留高回报率鼠标的原生框选。
- 修复高 DPI（含 175% 缩放）下连续钉图、再次截图导致图片逐渐模糊的问题。
- 界面任务结束后释放后台 WPF 功能进程，降低空闲占用；安装版与便携版均不附带诊断脚本，不启用输入或截图追踪。安装覆盖会清理早期测试包附带的已知诊断脚本，保留配置、模型和用户数据。

已知限制：部分电脑在空闲释放后首次显示工具栏仍有冷启动等待，本版没有通过长期保留整个界面进程来掩盖这一等待。艺术字识别效果仍受字体、背景、分辨率及裁剪完整性影响，不保证所有艺术字都能正确识别。

本次仅发布 Windows x64。安装版与便携版支持程序内更新；保留 ZIP 兼容下载，并提供小于 100 MB 的 7z 国内镜像包。
