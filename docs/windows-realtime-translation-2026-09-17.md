# Windows 实时翻译与界面语言验证（2026-09-17）

## 当前使用方式

- 实时翻译快捷键、托盘“实时翻译 / 停止”和设置中的开始入口均直接框选区域，不再打开实时翻译控制窗口。再次触发同一命令停止。快捷键默认留空，可在设置中配置，支持 Ctrl+数字。
- 框选后按所选 OCR、目标语言、模型精度和提供方顺序翻译；支持原位覆盖、悬浮字幕。译文不抢焦点、不阻挡鼠标，排除自身采集。设置中的字号、底板透明度和字幕位置继续有效。
- 术语表每行写 `原文=固定译名`，如 `Mana=法力值`、`shield=护盾`。按完整单词、区分大小写匹配，较长术语优先；绑定当前目标语言。占位符、数字及译文语言继续校验。
- 托盘左键单击启动普通截图；双击打开设置。单击须等待系统双击判定时间，避免双击同时触发截图。
- 设置 → 常规设置 → 外观与保存 → 界面语言支持简体中文、英语、法语、俄语、西班牙语、阿拉伯语，即时保存。界面语言与翻译目标语言独立，用户输入、路径、模型名称和 OCR／译文内容不随界面语言改写。

## 修复与资源行为

- 快捷键冷启动复用驻留端原生框选，仅传递选区坐标；功能进程已有时直接框选。取消时关闭选择层并释放首帧。
- 设置窗口主动隐藏后启动已有的闲置关闭机制。此前隐藏窗口仍被视为忙碌，使功能进程无法退出；现在实时翻译停止并等待采集、识别和翻译结束后，触发约 2 秒闲置退出。
- 停止会释放 WGC 会话、GPU 帧池、D3D 设备、原始像素、待处理帧、译文和图像指纹缓存。进程退出释放原生分配器和模型资源。没有新增后台常驻采集、强制清空工作集或阻塞式 GC。
- 多栏 OCR 按词框和像素修正边界，再按段落合并，避免横向串栏和将标题最后一行拆成独立翻译。浏览器 `aあ` 图标不再将整页已是中文的导航误判为日文。
- 经过校验的段落立即显示；页面角落的计数、时钟改变不再取消仍有用的整批翻译。变化检测按文字块隐藏过期结果，稳定段落继续显示。重复文字缓存最多 512 项，不积压截图。
- 离线补译组件的本机异常按本段失败处理，不再使整页已完成结果丢失；提供方中途抛错也会完成当前更新并保留成功译文。未完成段落保留原文并提示，不将其计入成功。
- 界面语言使用编译内置的静态词典，切换时只加载所选语言；无联网翻译、运行时模型加载或语言轮询。控件卸载时解除属性监听；阿拉伯语标签按从右到左阅读，不镜像截图像素与坐标。词典生成工具仅供开发，主要操作、主题名称和动态占位符另有人工校订。

## 后续反馈修复：语言遗漏与实时翻译框选（2026-09-17）

本节记录后续修复，以上进程号和测试数字为上一轮记录。Windows 以外文件未纳入本轮修改。

### 原因与修改

- 先前仅注册 `FrameworkElement.Loaded` 类处理器，WPF 会跳过没有实例／样式加载处理器的普通文字分支。原离屏用例给每个节点人工发送 Loaded，掩盖了导航、标题和主题名称漏译。现在首次实际布局也会接入本地化，动态提示在打开前补接入；撤掉设置预览用例中的人工 Loaded。卸载后解除属性监听，保留绑定和用户数据。
- 界面静态词典补充动态占位符、长说明、确认消息和服务状态。历史列表按 Run 更新文字，保留文件大小等绑定及排版；工具栏提示、后打开的菜单、系统文件选择器的应用自定义标题／筛选说明、辅助功能名称同步切换。应用确认弹窗使用主题控件和本应用语言，保留原有默认选项及取消含义。Windows 文件选择器的系统按钮仍由系统管理。
- 已打开功能进程时，实时翻译原先误调用普通截图编辑器，松手后仍等待截图确认，因而显示整套截图工具栏并不开始翻译。现在直接使用原生框选，冷／热入口都采用自由比例的物理像素坐标，松手立即提交选区；取消会结束选区任务并释放屏幕首帧。实时入口不启用取色。
- 用户网页中的大号 `75%` 与下方 `of developers…` 曾被拆开，缺少数字的半句会导致模型补出数字并被完整性检查拒绝。实时段落识别将同列、邻近且明确接续的百分比和正文合并，保留真实数字；跨列、远距离和独立标题不合并，数字校验保持严格。

## 远程画面不可见的根因与修复（2026-09-17 后续）

用户确认通过远程软件查看，只有外围黄色采集提示，没有选区边框和译文。旧版在译文 HWND 上设置 `WDA_EXCLUDEFROMCAPTURE`，这会让远程软件同样看不到整个译文窗口。此前直接渲染 WPF 视觉树的测试不能检出这个问题。

- 实时译文和边框改为正常可采集显示，保留鼠标穿透、不激活和 NonRudeHWND；不逐帧隐藏／显示或切换捕获排除属性。
- 框选结束后解析选区下面的应用 HWND，通过 WGC 读取该应用自身内容，再按窗口的物理坐标裁出选区，避免桌面浮层进入 OCR。不更改识别引擎、翻译提供方顺序、模型或用户配置。
- 选区下的窗口暂不可见或最小化时暂停采集；窗口关闭、移出选区、无法采集时显示原因，不回退到会反复读入译文的桌面采集。当前要求选区完整位于同一个文档／游戏窗口内，跨独立窗口时明确要求重新框选。新增提示包含六种界面语言。
