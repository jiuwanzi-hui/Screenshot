# Windows 水印功能与验证（2026-09-16）

## 范围与使用

- 仅修改 `Screenshot.App` 及 Windows 测试；未修改 Mac 或长截图算法。
- 常规设置增加“水印”页签，文字、截图时刻、地点可组合；最多导入三张图片、单选一张，也可仅使用文字信息。
- 图片导入本机 `ScreenshotData/Watermarks`，不上传。保留透明通道，导入上限 20 MB / 2400 万像素；预览按最长边限制到 600 像素，不放大窄长图片，截图导出使用原图片。
- 图案、正文、时间、地点为四个独立元素。预览点击或用“调整元素”选择后，可拖动位置、拖动右下角调整图片大小／字号、方向键微调及加减键缩放；Esc 撤销当前拖动。取消整体宽度滑块，保留不透明度和深色文字。默认图案在右上、文字在右下分开排列，位置与尺寸归一化，边缘不超出截图。
- 普通截图工具栏第二组新增“印”，默认位于钉图之前。再次点击取消；工具栏显示、顺序预览、快捷键配置同步支持。其他工具栏不新增此按钮。
- 自动添加默认关闭，打开后普通截图、上次区域直接截图和全屏直接截图使用预设；图片编辑、独立钉图框选、录屏及长截图不自动套用。
- 开关、文字输入、图片卡片、按钮、滑块及预览操作边框使用现有主题资源；水印自身黑白文字选择不因主题切换改变。

## 定位与资源生命周期

- 地点显示提供“地点名称（城市／地区，联网）”“经纬度（系统定位）”“手动填写地点”。原坐标预设继续使用坐标模式，不因升级自动上传坐标。编辑手填地点立即切到手动模式、取消未完成请求并更新预览；迟到结果不得覆盖手填内容。
- 城市模式使用 Windows 原生单次定位，再由本机直接向 BigDataCloud 查询中文城市／地区。设置附近明确说明联网与坐标发送，不查询其他设备、保存的坐标或 IP 推测地址。遵循[官方接口说明](https://www.bigdatacloud.com/geocoding-apis/free-reverse-geocode-to-city-api)及[客户端使用规则](https://www.bigdatacloud.com/docs/article/fair-use-policy-for-free-client-side-reverse-geocoding-api)。不是街道门牌级定位；不加载地图、不订阅定位、不常驻轮询。
- 系统取位置超时六秒，城市 HTTP 超时四秒且响应限制 64 KiB；系统授权对话框由 Windows 控制。拒绝授权、服务不可用、超时或城市结果为空使用手填备用地点并显示原因，不偷偷将城市模式改为经纬度或 IP 位置。
- 本轮未读取用户真实位置或代替用户授权；实际系统授权与坐标获取仍取决于本机定位服务。失败回退、禁用时不访问定位及取消后不发布结果已用可控提供方验证。
- 所有导入和图片解码在后台进行。切换离开设置页或关闭窗口取消未完成请求并释放缩略图、预览、鼠标捕获及保留的 DrawingVisual 绘制命令；不依赖隐藏元素再次 OnRender 才释放图片。
- 截图时间固定在本次编辑会话，预览与导出共用绘制实现。导出等待仍在加载的图片/位置，不会因异步未完成丢水印。取消或关闭会取消请求，迟到结果不回写。
- 水印层独立替换，定位完成时不会重建标注画布或移除用户正在输入的文本框。普通截图原始图像不被修改，取消水印后导出恢复原像素。
- 移动截图选区、拖动边框调整大小期间隐藏水印；松手并刷新新选区后恢复。隐藏状态在异步位置／图片完成和画布重新构建期间保持；隐藏仅影响交互预览，不丢失最终导出水印，不重复定位或解码。

## 独立布局修订验证（16:25 Release）

- Windows Release 编译成功；没有新增编译警告。新增 `WatermarkLayoutTests`，水印专项共 32 项通过。
- 水印、编辑画布、即时设置相关回归：109 通过，4 项真实桌面测试按默认策略跳过。
- 最终水印、选区移动、截图窗口和功能进程协议回归：84 通过，3 项真实桌面测试按默认策略跳过；上述两组有重叠，不能相加作为不同用例总数。
- 四种元素分别拖动、对角缩放、Esc 恢复、持久化；改变图片尺寸不改变文本字号。24×18、770×545、300×1600、3840×2160 的边界与最终像素输出通过。预览移动后的旧区域恢复背景，没有残留图像。
- 已定位成功后手填、等待定位时手填、迟到定位返回、坐标／地点／手动切换、隐藏页面清除预览通过。城市 JSON 的省市去重、地区组合、空字段及拒绝 IP 回退通过；本轮没有向外部服务发送真实用户坐标，未宣称已完成本机真实城市查询验证。
- 隐藏 HWND 验证工具栏至真实导出、选区调整控件隐藏／恢复水印、隐藏期间关闭水印；另测异步新内容在隐藏期间到达及重新裁取后仍保持隐藏、恢复后显示新布局。
- 使用本次实际 App 资源离屏检查墨湾流光、清透琉璃、青瓷月桂；没有在桌面显示测试图案。实际物理鼠标与各硬件档位仍需用户场景验证。
- 初次测试发现重复裁剪使字形抗锯齿边缘与直接导出不同，已删除多余子窗口裁剪，保留合成器和画布边界裁剪；逐像素导出回归通过。预览擦除测试修正为比较当前主题背景，不假设所有主题背景为透明黑色。
